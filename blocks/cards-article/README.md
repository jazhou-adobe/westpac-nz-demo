# cards-article

Custom **cards** block. Purpose: news-teasers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- default (small): 178px images; 1 tile per view <576px, 2 per view 576-991px (scroll-snap row with prev/next arrows), 4-column grid >=992px.
- `large` (`Cards Article (large)`): 276px images; 3 tiles per view >=992px with prev/next arrows (source `.slick-slider--large`, e.g. business "Closer to what you want to do.").
